# vclient

Клиент клиент-серверной системы обработки данных (курсовая работа по ТиМП, вариант 22).

- исходные данные: текстовый файл, числа int64_t;
- результаты: двоичный файл (uint32_t количество + int64_t значения);
- аутентификация: SHA-224, соль генерирует клиент.

Требуются g++, make и Crypto++ (`libcrypto++-dev`).

```
make
./vclient -a 127.0.0.1 -p 33333 -i vectors.txt -o result.bin -c ~/.config/vclient.conf
```

Файл учетных данных: первая строка — логин, вторая — пароль.
